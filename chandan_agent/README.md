# Chandan Agent

Chandan Agent is a production-ready local AI computer agent. It runs primarily on Windows and allows secure remote control from a mobile-first web dashboard.

## Features
- Local Agent Core
- Secure FastAPI Gateway
- Mobile Web/PWA Control Panel
- AI Orchestrator
- Tool/Function Registry
- Permission Manager (4 Levels)
- Task Execution & Verification
- Project Intelligence Engine
- Browser Automation Engine
- Video Generation Pipeline
- Social Publishing Connectors
